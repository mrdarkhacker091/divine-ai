# Divine AI

An independently developed language model
trained from randomly initialized weights.

## Project goals

- Custom tokenizer
- Decoder-only Transformer
- English and Nigerian Pidgin support
- Independent training pipeline
- Model checkpoints
- Text generation
- Independent API

## Architecture

Model: Divine AI
Type: Decoder-only Transformer
Initialization: Random
Training: Next-token prediction
Languages: English and Nigerian Pidgin

## Training environment

Android Termux: Development
Google Colab: Model training
